# 重建版本核查说明

本序列依据现有 v0.3.0 源码重建，并非从真实 Git 历史恢复。各提交时间为整理时人为指定，推送时间为实际执行时间。v0.1.0 至 v0.2.5 使用独立简化实现；v0.3.0 切换到原始完整应用。v0.2.5 提供 Excel 地址迁移表，使用限制见 README。

已验证 Windows 构建、Go 测试与 go vet；实际飞书长连接、托盘、开机启动、各版本交互及所有升级场景未全面验证。当前环境缺少 C 编译器，无法运行 Go race 检测。应用配置和连接状态被后台任务、飞书回调和桌面操作并发访问，仍存在数据竞争风险，应在生产使用前完成同步改造和竞态测试。

组件 URL 导入限制直接连接公开地址并禁用代理；网络地址分类不保证涵盖所有特殊用途或组织内部路由。开源许可文件目前仅为版权声明，不授予开源许可；需由权利人选择许可证。钉钉、企业微信和第三方组件执行尚未实现。
