# 飞书命令

| 输入 | 作用 |
| --- | --- |
| `15` | 检查当前网段的 `.15` |
| `/ping 15` | 检查当前网段的 `.15` |
| `/vi 15` | 检查设备列表中的 `.15`，返回名称、设备区域、IP 和检测信息 |
| `/vi all` | 批量检测设备列表全部设备，发送在线/无法连接巡检表 |
| `/vi no` | 批量检测全部设备，只发送无法连接设备表 |
| `/20 15` | 临时检查 `192.168.20.15` |
| `/110 15` | 临时检查 `192.168.110.15`；`0`～`255` 都可作为第三段 |
| `/net` | 查看当前网段 |
| `/net 192.168.30` | 管理员修改默认检测网段 |
| `/status` | 查看客户端状态 |
| `/help` | 查看帮助 |

`/vi` 的单设备和批量巡检目前固定使用 `192.168.20.x`，适用于监控设备巡检场景；`/ping` 和纯数字命令使用“设置”中配置的默认网段。
