# XinT-LanPulse v0.2.5（重建版）

Windows 内网连通性检测雏形，支持 IPv4 地址检测、自定义超时和尝试次数，显示最近 20 条本次检测记录，并支持维护本地设备地址清单和可配置 1～16 路并发批量检测，JSON 清单导入导出（导入时合并）运行期间定时检测，以及设备最近一次检测结果。定时任务关闭窗口后停止，重启需重新开启。

需要 Go 1.26 与 Windows WebView2。运行 `go test ./...` 验证，运行 `go run ./cmd/xint-lanpulse` 启动。

本版本根据现有源码重建，并非从原始 Git 历史恢复。设备清单、地址和检测参数保存在当前用户的 WebView 数据中，升级至其他实现时不会自动迁移。

升级到 v0.3.0 前，可导出 Excel 迁移表并在新版设备台账导入。该格式仅支持 `192.168.20.1` 至 `192.168.20.254`，其他地址须先从清单移除；名称和区域需在新版补充。JSON 清单不能直接导入 v0.3.0。
